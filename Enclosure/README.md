## Assembly Instructions for `fgFocus`

1. **Attach the light sensor**
   Insert the light sensor into the PCB so that the mounting holes on both parts line up correctly.

2. **Install the spacers**
   Place the four spacers onto the mounting posts on the bottom half of the enclosure. These keep the PCB from resting directly on the surface. Ensure the USB-C port is positioned so it lines up with the enclosure’s USB opening.

3. **Insert the bolts**
   From underneath the enclosure, insert the four M3 bolts upward so they pass through the enclosure, the spacers, and the PCB.

4. **Close the enclosure**
   Place the top cover onto the enclosure, then secure it by tightening the provided screws and nuts.
